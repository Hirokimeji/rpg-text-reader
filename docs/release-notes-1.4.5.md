# 台词拾光 1.4.5

不方便联网时，请下载 **textlight-1.4.5-windows-x64-offline.zip（离线增强版，约 228 MB）**。完整解压并保留“增强读取组件”文件夹，即可读取已适配的封装游戏，无需额外下载组件、安装 Docker 或 WSL。

普通便携版体积更小；使用增强读取时，首次需下载约 152 MB 的组件。单独的 Textlight.exe 属于普通版。

本次更新：

- 直接读取标准 VX Ace `.rgss3a` 数据包；选择游戏 EXE 或文件夹时自动查找数据包。
- 部分 VX Ace EXE 封装可自动尝试隔离读取，自动查找同目录中的原始 EXE 备份；完成或取消后清理临时副本。
- 自动读取 Langscore 中文 CSV 翻译表，保留原译对照，空译文保留原文。
- 支持已识别汉化插件的加密 JSON；读取失败或缺少索引地图时，在界面、报告和导出文件中提示缺失范围。
- 可读取 MTool 地图缓存中的事件片段，并明确标记为片段；增强读取失败时保留可用缓存。

游戏和文本不会上传，原游戏文件不会修改。保护封装并非全部兼容，图片文字和压缩 Ruby 脚本中的动态文字仍可能缺失。
