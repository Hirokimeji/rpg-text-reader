## 新图标

更新为薄荷绿像素角色图标：手持发光台词本，呼应“台词拾光”的文本阅读主题。

- Windows EXE 图标与应用窗口图标统一更新。
- 图标包含 16、24、32、48、64、128、256 像素尺寸，适配不同显示大小。
- GitHub README 图标同步更新，源码包含透明 PNG 原图与 ICO 文件。

本版继续支持 RPG Maker MV / MZ / VX Ace、SRPG Studio 未加密标准项目及 MTool 翻译字典。

下载 `textlight-1.2.1-windows-x64.zip`，解压后运行 `台词拾光.exe`；也可单独下载 `Textlight.exe`。升级时关闭旧版，改用新版 EXE 即可。
