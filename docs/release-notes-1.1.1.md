台词拾光是一个适合普通用户使用的 Windows RPG Maker 文本参考阅读器。

下载 `textlight-1.1.1-windows-x64.zip`，解压后双击里面的 `台词拾光.exe`。无需安装 Python、Excel 或 MTool。

本版包含：

- 自动识别 MV / MZ 标准 JSON 数据、VX Ace 已展开的 `.rvdata2` 数据。
- 读取游戏内文本，或关联 MTool 的原文—译文 JSON 字典。
- 按地图、事件、事件页阅读和搜索，支持原译对照及跨页复制。
- 汇总或按场景拆分导出 TXT / Excel。
- TXT、连续阅读和复制内容不再重复插入触发条件、开关编号等说明。

工具在本机处理，不修改游戏文件。暂不支持 XP / VX、RGSS 加密归档、图片文字及部分动态脚本文字。

`SHA256SUMS.txt` 提供附件校验值。源代码也可以在仓库首页查看。
