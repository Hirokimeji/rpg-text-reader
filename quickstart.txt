台词拾光 1.4.5 — 游戏文本参考阅读器

【开始使用】
双击“台词拾光.exe”，不需要安装 Python、Excel 或 MTool。
选择游戏文件夹，也可以拖入游戏文件夹、游戏 EXE、标准 .rgss3a 数据包或翻译 JSON。
也可将工具及组件文件夹一起放进游戏目录，双击自动识别。

【选哪种文本】
游戏本身已经汉化：读取游戏内文本即可。
使用 Langscore 汉化：自动读取 data/translate 或 data/translates 中的中文 CSV。
使用 MTool 翻译：选择对应翻译 JSON。发现多个版本时请选你实际使用的版本。
翻译文件不在游戏目录：先打开游戏，再点击“切换翻译文件”。
只打开翻译 JSON 也能阅读和导出，但没有游戏数据就无法还原场景。

【找台词】
默认显示剧情对白、滚动文字和选项。
左侧按地图、事件、事件页找场景；公共事件另列。
Unity 游戏按资源对象／剧本分组，不代表实际游玩顺序。
顶部可搜索原文、译文、角色或场景，切换“所有文本类别”可查看物品等内容。
点击一条文字，右侧显示阅读内容、原文、译文和来源。
“连续阅读”适合看上下文；“复制当前筛选结果”包含列表其他页的文本。

【导出】
点击右上角“导出文本”。
范围可选：当前筛选结果、全部文本、选中的文本。
TXT 适合阅读；Excel 适合筛选、整理和对照。
勾选“场景拆分”，会按每个场景分别生成文件。
每次导出建立新的结果文件夹，不会覆盖已有结果。

【支持的游戏】
RPG Maker MV、MZ：可读的标准 JSON 数据。
RPG Maker VX Ace：已展开的 .rvdata2、标准 .rgss3a 数据包及部分 EXE 封装。
SRPG Studio：1.140–1.322 的标准 data.dts（含标准加密），支持地图、事件、对白和数据库文本。
SRPG Studio 的外部 language.dat／localization.dat 翻译层及非标准加密暂不支持。
Unity：支持标准 TextAsset、StreamingAssets 文本及可解析的托管对白对象。
Unity 缺少类型树时尝试读取 Managed 元数据；暂不恢复 IL2CPP 缺失类型树，不处理加密资源。
MTool：原文与译文都是字符串的 JSON 字典。
XP、VX 和未适配的特殊保护封装暂不支持。

【几个提示】
只有 MTool 地图缓存时，可读取缓存中的事件片段；这不包含完整游戏文本。
遇到文件未能读取时，窗口会提示“部分内容未读取”；请点“提取报告”查看缺少哪些文件。
已适配的汉化插件加密文本可自动读取，其他自定义加密仍可能不支持。
未匹配：显示原文。部分匹配：还有一部分原文没有译文。
游戏内文本：游戏文件中现存的文字，不表示工具自动判断了是否汉化。
〔变量#编号〕等是游戏运行时决定的内容；未知控制符会保留。
场景顺序不等于剧情游玩顺序；同一句话在不同场景会分别保留。
角色名没有可靠信息时留空；没有译文不会自动翻译。
图片里的文字和部分脚本动态文字可能无法提取。

封装游戏会自动尝试增强读取。离线增强版已包含组件，不需要联网。
普通版首次需下载约 152 MB 的组件，之后可离线使用。
请保留 EXE 旁的“增强读取组件”文件夹，不要只复制单独的 EXE。
请保留完整游戏文件夹及原始 EXE 备份；压缩包先解压再选择游戏。
读取过程中可点击取消，临时副本会在结束后清理。
工具不上传游戏或文本，也不会修改游戏目录。
完整说明见“使用说明.md”。“源代码”和“第三方许可”不影响日常使用。
